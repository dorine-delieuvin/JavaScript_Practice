# JavaScript Practice

This repository is to regroup the projects I have been working on to practice my JavaScript skills.
Most of which are from the Codecademy's ['Learn JavaScript' course](https://www.codecademy.com/enrolled/courses/introduction-to-javascript)

Those projects use post ES6 JavaScript, they are developed and ran locally in VS Code editor.
This requires node.js v23.7.0 to be installed to run .js scripts in VS Code ([current version](https://nodejs.org/en/download/current)).
